🤖 AI Configuration

Configure your OpenAI API key to enable full AI chat functionality. Without an API key, the assistant will use offline responses.

Your API key is stored locally and never shared. Get one at platform.openai.com
💡 How to get an API key:
1. Visit platform.openai.com
2. Sign up or log in to your account
3. Go to API Keys section
4. Create a new secret key
5. Copy and paste it above

🚀 Getting Started

LightFrame is designed to assist you during interviews and meetings by providing an AI chat interface that remains hidden from screen sharing and recording software.

⌨️ Keyboard Shortcuts

Ctrl + Alt + M - Quick help and tips
Ctrl + Alt + J - System status check
Ctrl + Alt + K - Focus mode activation
Ctrl + Shift + T - Toggle click-through mode

🔧 Troubleshooting

App not staying on top: Check if other applications have focus-stealing behavior.

Global shortcuts not working: Ensure no other applications are using the same key combinations.

AI not responding: Configure your OpenAI API key in the AI Setup tab.
